       - Validar HMAC SHA256

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐

    ✅ ETAPA 3: Processar fila
       - Loop: redis.lRange('queue:messages', 0, 0)
       - Desserializar JSON
       - Extrair dados

       - Buscar últimas 10 mensagens da conversa

            }
          }
        }
      }]
    }

    ✅ ETAPA 6: Parsear resposta
       - Verificar se toolCall existe
       - Tipo: pdf | xlsx | docx

    ✅ ETAPA 7: Gerar arquivo
       
       SE toolCall.type === 'xlsx':
         → Chamar backend: POST /v1/multimodal/export/xlsx
         → openpyxl gera Excel com:
            • Cabeçalho colorido (#1E293B)
            • Linhas alternadas (#F1F5F9)
            • Wrap text para conteúdo longo
            • Largura automática de colunas
            • Freeze panes
            • Auto-filter
         → Retorna bytes (45.32 KB)

       SE toolCall.type === 'pdf':
         → Chamar backend: POST /v1/multimodal/export/pdf
         → ReportLab gera PDF com:
            • Capa profissional
            • Sumário
            • Seções com tabelas
            • Encerramento
         → Retorna bytes (120 KB)

       SE toolCall.type === 'docx':
         → Chamar backend: POST /v1/multimodal/export/docx
         → python-docx gera Word com:
            • Título
            • Seções com cabeçalhos
            • Tabelas reais
            • SEM rodapé
         → Retorna bytes (80 KB)
